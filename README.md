# 动句 · 描述即动作短视频

根据自然语言描述，解析人物动作序列并在舞台上表演，支持浏览器内导出短视频（WebM）。

## 使用

```bash
python3 -m http.server 8080
```

打开 http://localhost:8080

1. 在输入框写下动作描述（或点示例）
2. 点 **预览** 观看角色表演
3. 点 **导出短视频** 下载 `.webm` 短片

## 支持的动作词

挥手 / 招手 / 打招呼 · 走路 · 跑步 · 跳跃 · 跳舞 · 鼓掌 · 鞠躬 · 坐下 · 点头 · 庆祝

描述里出现的动作会按出现顺序串成短片，最多 6 段。

## 示例

- `挥手打招呼，然后鞠躬致意`
- `跑步冲刺，再跳跃庆祝，最后鼓掌`
- `坐下休息，站起来点头，再跳舞`
