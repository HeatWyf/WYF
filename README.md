# StampJoy · 盖章奖励卡

儿童主题奖励盖章卡（Reward Chart / Stamp Card）模板，可在浏览器里点按盖章，填写名字与奖品后直接打印。

## 使用

用任意静态服务器打开，或直接双击 `index.html`：

```bash
python3 -m http.server 8080
```

然后访问 http://localhost:8080

## 主题

- 消防员
- 足球
- 太空
- 独角兽
- 小狐狸（上学）

每张卡为 5×5 共 25 个印章位，含 NAME / PRIZE 填写区与主题插画。

- 可打印页面：[`worksheets/addition-subtraction-2-redesign.html`](worksheets/addition-subtraction-2-redesign.html)
- **图形题**：气球 / 小鱼分堆写算式、青蛙数轴跳格、数字磁贴选题、书架场景应用题
